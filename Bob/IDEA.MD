For this competition, we propose a programmable macropad called "Manifest".

This macropad allows developers to increase their productivity by programming different keys for common development tasks such as:
- Running a program
- Compiling
- Copy & Paste
- Opening a Local server
- Creating new files/folders
- Speech to text

etc.

The macropad will be created using an MCU programmed with the assistance of IBM Bob.

It will be USB Powered, have clicky (Satisfying) buttons for each command and open source (so other developers can modify the buttons by uploading their own code).

The goal of this keypad is to make development quicker by taking away repetitive tasks and more fun by giving the programmer a better sense of control.
