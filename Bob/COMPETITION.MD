The Challenge

Build with purpose using IBM Bob 2.0

Create a solution that improves a specific developer workflow, such as onboarding, debugging, code review, testing, application maintenance, or release and deployment processes. Start by clearly defining a problem where time, effort, or errors are too high today. Then, using IBM Bob 2.0, build a working prototype on a real or sample project that demonstrates a full solution to improve the specified workflow. Leverage features like Agent mode, parallel tasks, subagents, and document understanding to manage and improve multiple steps, not just assist with coding. Clearly demonstrate impact by showing how your solution increases productivity, reduces manual effort, errors, and rework, or significantly shortens the time required to complete tasks.

Using IBM Bob 2.0, you'll build a working prototype that improves one or more areas of the software development lifecycle, such as:

Onboarding
Debugging
Code review
Testing
Application maintenance
Release and deployment workflows
The strongest submissions will clearly demonstrate measurable impact—whether that's reducing manual effort, eliminating errors, saving time, or improving the overall developer experience.



Build with IBM Bob 2.0

Participants should leverage the capabilities of IBM Bob 2.0 in their solution, including features such as:

Agent Mode
Subagents/Parallel tasks
Document understanding
Think beyond code generation—show how AI can transform an entire development workflow.

What Makes a Great Submission?

The best projects will:

Solve a meaningful developer challenge with a clear, well-defined approach.
Demonstrate effective use of IBM Bob 2.0 to enhance or automate a developer workflow.
Deliver a polished prototype that is functional, easy to understand, and intuitive to use.
Show real-world value by improving productivity, reducing friction, or simplifying complex processes.
Bring a creative perspective to the problem while presenting a solution that could realistically scale or be adopted.
Remember: You don't need to build something enormous. Focus on solving one problem exceptionally well and clearly communicating the impact of your solution.
